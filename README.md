# PLUS student-facing Intro Video

This video is built with [HyperFrames](https://hyperframes.heygen.com): every scene is an HTML page
animated with GSAP and rendered to MP4. The whole film can be edited as text and re-rendered.

| | |
|---|---|
| Script (narration, word for word) | [`script.md`](script.md) |
| Shot list | [`STORYBOARD.md`](STORYBOARD.md) |
| Visual style (from the PLUS Teacher Handbook in Figma) | [`design/brand.md`](design/brand.md), [`design/tokens.css`](design/tokens.css) |
| Finished videos | GitHub **Releases** of this repo (MP4 files are not committed) |

## Project layout

```
index.html              root composition (generated by tools/build_index.py)
compositions/           one HTML file per scene: welcome, tutor, start, breakout, joins, goals, stepout, outro
assets/
  brand/                PLUS logo, mascots, CMU wordmark (from Figma / Wikimedia Commons)
  doodles/              hand-drawn icons (generated by tools/node/doodles.mjs)
  voice/                voiceover: vo-full.mp3, per-section s1–s8.mp3, vo_meta.json (word timings)
  sfx/                  sound effects (see assets/sfx/CREDITS.md)
  photos/plus-team.webp PLUS team photo
  fonts/, vendor/       DM Sans, GSAP
tools/
  build_index.py        writes index.html: scene slots from the voiceover timings, sound effects, camera pans
  make_vo_heygen.py     regenerates the voiceover from script.md with HeyGen
  make_vo.py            alternative free, local voiceover (Kokoro)
  node/doodles.mjs      regenerates the hand-drawn icons (rough.js)
.claude/skills/         HyperFrames skills used by Claude Code to build and edit the film
```

## Preview and render

Requires Node 18+ and Chrome/Chromium. From the repo root:

```bash
npx hyperframes preview          # live preview in the browser (Studio)
npx hyperframes check            # lint + layout checks
npx hyperframes render -o renders/plus-intro.mp4
```

Inside Claude Code the skills run the CLI through `node .claude/skills/hyperframes/scripts/plugin-cli.mjs <command>`.

## Making changes

- **Visuals or timing of one scene:** edit `compositions/<scene>.html`. Each animation step is commented with the line of narration it belongs to.
- **Narration text:** edit the VO in `script.md`, then regenerate the voiceover and the scene slots:
  ```bash
  HEYGEN_API_KEY=... python3 tools/make_vo_heygen.py script.md assets/voice 95d52e056b7b495dab8f090b44fa2ec4
  python3 tools/build_index.py
  ```
  New narration changes word timings, so re-check the cues in the scenes that changed.
- **Icons:** edit `tools/node/doodles.mjs`, then `cd tools/node && npm install && node doodles.mjs`.

Secrets (Figma token, HeyGen API key) are never committed; they live in the cloud environment settings.
